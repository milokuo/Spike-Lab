# M2.3 發球重設計＋第一人稱視角 規格（orchestrator 拍板版）

> supersedes docs/m2.2_spec.md §4（發球）與 m2.1 的鏡頭章節部分內容。打破協定允許。未提及處沿用現狀。

## 1. 發球蓄力（回饋修正）
- **刪除 SERVE_MIN_CHARGE 地板**（shared 常數與 server 用法全刪）：發球蓄力從 0 開始、HUD 顯示原始值。
- 太軟的發球自然失敗（掛網、落自家半場）→ 依既有死球規則判對方得分。發球失誤是合法的節目效果。

## 2. 發球區移動限制
- 常數：`BACK_BOUND_Z = COURT_HALF_LENGTH + 5`（=14，所有階段全員通用的後界）。
- 發球階段、球未發出、發球者**在地面**時：clamp `|z| ≥ COURT_HALF_LENGTH`（不得進場）。x 維持場寬內。
- **空中不 clamp**：起跳必然發生在線後，空中越線合法（真實排球規則）；球發出後完全解除限制。
- 其他玩家不受此限制（本來就在場內）。

## 3. 量角器發球（angle-sweep serve）

### 3.1 指針＝純函數（鐵律，見 §6.4 同哲學）
```
serve 階段進入時 server 廣播 phaseStartServerTime（快照帶或既有 phase 訊息帶）
sweepAngleDeg(elapsedMs) = 三角波：
  SERVE_SWEEP_PERIOD_MS = 1600      // 左→右 800ms、右→左 800ms，往復
  phase = (elapsedMs mod P) / P
  angle = phase < 0.5 ? -90 + 360×phase : +90 − 360×(phase−0.5)   // ∈ [-90, +90]
放 shared（如 kinematics/serveSweep.ts），有單元測試（端點、週期、對稱）。
client：用同步後的 server clock 本地渲染指針；server：用延遲補償後的放開時刻代入同函數＝權威角度。
不新增任何 wire 欄位。
```

### 3.2 行為
- 發球階段，發球者按住左鍵蓄力（從 0），玩家前方渲染一個 **180° 半圓量角器**（面向網），指針依 §3.1 掃動。
- 放開左鍵＝出手：水平方向 = 「朝網方向」繞 Y 軸旋轉 `angle`；距離/力道 = 蓄力（沿用蓄力→速度管線）；dirInput 不再用於發球瞄準。
- 蓄力中玩家可自由移動（含後退，受 §2 clamp），指針照常掃動。
- 量角器渲染：薄環/扇形 mesh 或 sprite 貼在玩家前方地面上緣即可，指針一根線；不用做精美，可讀就好。對手端也渲染（可讀性鐵律——同純函數大家都算得出）。

### 3.3 跳發（jump serve）
- 放開左鍵瞬間發球者**在空中**（jump state 非 grounded）＝跳發：
```
出手點：手部高度 = SERVE_HAND_HEIGHT + 當前跳躍 y
SERVE_JUMP_SPEED_MULT = 1.25        // 球速加成
弧線：更平、帶向下分量（從高點打下去；實作＝依出手高度解算過網下墜弧線）
品質：SERVE_QUALITY_GROUND = 0.8 → SERVE_QUALITY_JUMP = 0.95（散射更小，§6.3 管線）
耐力：發球觸球成本 ×2（spec §9 跳發規則）
```
- 地面發球品質 = SERVE_QUALITY_GROUND（原本寫死的值換成常數）。

## 4. HUD 九宮格（右下角）
- 位置：**右下角**，半透明，不擋中央畫面。
- 佈局（中排 4 格，其餘 3 格）：
```
        [U] [I] [O]
  [發球] [J] [K] [L]
        [M] [,] [.]
```
- J/K/L：現有模式，當前模式高亮（沿用藍/綠/紅色系）。
- U/I/O/M/,/.：技能槽（M3 才有內容），顯示「空槽」樣式（虛線框＋鎖/－ icon）。
- [發球] 格：serve 階段且輪到自己發球時高亮（含小球 icon 或「發」字），其他時間灰暗。
- 舊的橫排模式徽章移除；控制提示列保留並更新。

## 5. 第一人稱視角（FPV）

### 5.1 切換與鏡頭
- `V` 鍵切換 第三人稱 ↔ 第一人稱（HUD 提示列註明）。
- FPV：requestPointerLock（滑鼠隱藏）；mouse X = yaw、mouse Y = pitch（clamp ±60°，僅影響視角不影響移動）。鏡頭掛在頭部（`PLAYER_HEIGHT × 0.9`）。
- 進入 FPV 時 yaw 初始化為「面向網」（依 side）。Esc/pointer lock 丟失 → 自動退回第三人稱（顯示短提示）。
- 左鍵蓄力/出手在 pointer lock 下照常運作；lock 中不可能點到 UI，UI 過濾邏輯不得誤擋。

### 5.2 移動座標系（架構決策）
- `InputFrame` 新增 **`yaw: number | null`**（radians；null＝第三人稱）。
- shared 新增唯一轉換函數（放 viewSpace.ts）：
```ts
moveToWorld(move: Vec2, side: Side, yaw: number | null): Vec2
// yaw === null → 現有 viewToWorld(move, side)（side 鏡像）
// yaw 為數值   → 以 yaw 旋轉 move（W=視線前方投影到地面）
```
- client 預測與 server movement **都改呼叫 moveToWorld**；TouchIntent.dirInput 同樣管線（FPV 下方向鍵意圖以 yaw 轉換）。
- server 驗證 yaw：有限數值、wrap 到 [-π, π]；非法→ 當 null 處理。
- 第三人稱行為完全不變（yaw=null 路徑＝現狀）。

## 6. 工作包
- **WP1 shared**（機械）：刪 SERVE_MIN_CHARGE；BACK_BOUND_Z=14；serveSweep.ts 純函數＋測試；SERVE_JUMP_SPEED_MULT/SERVE_QUALITY_GROUND/SERVE_QUALITY_JUMP 常數；InputFrame.yaw；moveToWorld(move, side, yaw)＋每側/每 yaw 象限測試。全綠 ≥80%。
- **WP2 server**（推理）：發球地面 clamp（§2，空中免除）；量角器權威角度（§3.1 以 lag-comp 放開時刻）；跳發判定（放開時 airborne → §3.3 全套）；地板刪除後的軟發自然死球驗證；movement 改 moveToWorld；phaseStartServerTime 廣播。smoke/integration：軟發失分、地面發 vs 跳發（速度/品質/出手高差異斷言）、角度確定性（同放開時刻雙端同角度）、yaw 移動、serve clamp（地面推進被擋、空中越線 OK）。
- **WP3 client**（推理）：蓄力條從 0；量角器渲染（自己＋對手端）；跳發（既有跳躍＋空中放開即可，無新輸入）；HUD 九宮格右下（§4）；FPV：V 切換、pointer lock、yaw/pitch、鏡頭、移動與 dirInput 走 yaw、退出處理（§5）。typecheck/build 綠。
- **WP4 整合**（推理）：全量測試＋latency bot 適配（yaw 欄位、發球角度探針）＋README（發球玩法、V 鍵、九宮格）。
