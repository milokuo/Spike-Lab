# M2.4 實測修正輪 規格（orchestrator 拍板版）

> 增補於 m2.3 之上。未提及處沿用現狀。

## 1. 發球階段本地跳躍渲染 bug（P0）
- 症狀：自己發球時按跳，**自己畫面**看到球被上拋、角色不動；**對手畫面**正常（角色跳、球跟手）。
- 假說：本地角色膠囊 Y＝預測值，但持球點/量角器掛在 server 快照位置 → 兩來源在本地不一致（快照 Y 先跳，膠囊沒跟）。實作者先驗證此假說再修。
- 修法原則：**本地玩家的所有附著物（持球、量角器）一律掛本地預測位置**；遠端玩家照舊掛快照。修完自己畫面：人跳、球在手上跟著跳。

## 2. FPV 失焦不退出
- pointer lock 因跳窗/失焦/Esc 被瀏覽器強制解除時：**FPV 模式保持**（鏡頭仍第一人稱），僅顯示覆蓋提示「點擊畫面恢復視角控制」；點擊 canvas 重新 requestPointerLock。
- 只有 `V` 鍵是唯一「退出 FPV」的途徑。lock 解除期間滑鼠可見、輸入照常（yaw 凍結在最後值）。

## 3. 跳發球視覺
- `BallLaunch` 新增 `isJumpServe?: boolean`（server 於跳發時設 true）。
- client：isJumpServe 的球體變色（橘紅 emissive 發光）＋軌跡殘影同色調，直到該球下次觸碰/死球恢復。強度可讀即可。

## 4. 二次開房殘留渲染（P0）
- 症狀：打完一場回選單再開/加入新房，前一場的角色 mesh 殘留在場景。
- 修法原則：房間生命週期收斂到單一 teardown——離開房間（主動離開、gameover 返回、斷線）時清除：所有玩家 mesh、球、量角器、飛撲/演出狀態、HUD 名單與比分；加入新房時從乾淨狀態重建。禁止靠「覆蓋」而不清除。

## 5. 過蓄（Overcharge，紅線第二段）
```
蓄力值 c 上限由 1.0 → OVERCHARGE_MAX = 1.3
c ∈ [0, 1.0]：現狀（力量線性、無懲罰）
c ∈ (1.0, 1.3]：紅區。累積速率沿用 CHARGE_RATE（1.0 之後再 ~0.375s 到頂）
  力量：沿用現有 charge→距離/速度管線直接吃 c（>1 力量繼續增加＝「力量過多」）
  品質懲罰：overchargeQualityMult(c) = 1 − OVERCHARGE_QUALITY_PENALTY × (c − 1) / (OVERCHARGE_MAX − 1)
           OVERCHARGE_QUALITY_PENALTY = 0.5   // 頂紅 → 品質 ×0.5
  server：quality ×= overchargeQualityMult(c)（所有觸球含發球）；TouchIntent.charge 驗證 clamp [0, 1.3]
shared：常數＋overchargeQualityMult 純函數＋測試（1.0 無懲罰、1.3 → 0.5、線性、clamp）
client：蓄力條延伸紅段（右端 23% 紅色區），蓄到紅區時條閃爍/變紅提醒
```
