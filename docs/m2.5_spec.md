# M2.5 角色視覺：名牌、臉、程序化手臂 規格（orchestrator 拍板版）

> 增補於 m2.4 之上。純視覺＋一個小 wire 欄位；判定邏輯零改動。

## 1. Wire：朝向（facing）
- `PlayerSnapshot` 新增 `facing: number`（radians，同 yaw 慣例：0=+Z、右手系 Y 旋轉）。
- server 計算：`yaw`（InputFrame 有值時）＞ 移動方向（速度向量非零時，取水平朝向）＞ 維持上一值 ＞ 初始面向網（side A→π 或 0 依現有慣例，面向 z=0 網）。
- client 本地玩家不等快照：FPV 用自己 yaw、第三人稱用移動方向（同上優先序）本地即時算；遠端用快照 facing（插值平滑轉向，避免瞬跳）。

## 2. 角色構型（純 client，scene/player.ts 系列）
- **身體**：現有膠囊（保留模式 tint 藍/綠/紅）。
- **頭**：球體，貼 CanvasTexture 卡通臉（兩眼＋嘴，簡單黑線條；PERFECT 觸球後 1 秒可換開心臉、WHIFF/撲空換囧臉——用 2~3 張 texture 切換，低成本高笑果）。
- **手臂**：兩根細膠囊/圓柱，pivot 在肩（身體上部兩側）；整個角色包成 Group，Group.rotation.y = facing。
- **名牌**：頭上 billboard sprite（CanvasTexture 畫名字，描邊白字），永遠面向鏡頭；FPV 隱藏自己的名牌與頭/手臂（避免擋視線——FPV 只渲染自己雙臂前伸的簡化版或干脆全隱藏，實作者擇一，註明）。

## 3. 程序化手臂動畫（無骨架，quaternion slerp 姿勢機）
- 姿勢機每幀輸出左右臂目標旋轉，slerp 平滑過渡（~8-12/s 速率）：
```
idle/move : 依水平速度擺動 swing = sin(t × freq) × amp × speedFactor，左右反相
charging  : 依 touchMode 預備姿勢（可讀性＝心理戰，對手看得到）：
            dig   雙臂前下伸、掌心向上合攏
            set   雙手舉過頭、肘微張（托球框）
            spike 慣用臂後拉過肩、另一臂前平衡（引弓）
touch     : TouchResult/出手瞬間起 ~0.4s：肩樞軸朝「球當下渲染位置」方向解一個 aim 向量，
            dig=雙臂合掌沿 aim 上撈；set=雙手沿 aim 上推；spike=慣用臂沿 aim 過頂下劈
jump      : 雙臂上揚 20~30°（疊加於當前姿勢）
dive      : 雙臂沿撲出方向前伸（蓋過其他姿勢，DIVE_LOCK_S 期間維持）
serve hold: 一手前托球（球已掛此位置），另一手自然下垂；放開出手→ spike 揮擊
優先序：dive > touch(0.4s) > charging > jump 疊加 > idle/move
```
- 遠端玩家同樣走姿勢機：mode（快照有）＋TouchResult 廣播（有）＋facing（新）都拿得到，表現一致。
- 常數集中（swing 頻率/幅度、姿勢角度、slerp 速率、touch 姿勢時長）於 client 常數檔，方便調。

## 4. 工作包
- **WP1 shared+server**（Sonnet）：PlayerSnapshot.facing 型別；server 依 §1 優先序計算並寫入快照（存 per-player 上一值）；smoke 補一條 facing 斷言（yaw=π/2 → facing=π/2；純移動 → 朝移動方向）。全綠。
- **WP2 client**（Opus）：§2＋§3 全部；名牌；臉 texture ×3（普通/開心/囧）；FPV 自身處理；typecheck＋build 綠；README 一行提及。
- 驗證併入 WP2 尾：跑 server smoke（確認 wire 相容）＋shared 測試。latency bot 不受影響（snapshot 新欄位向後相容），不動。
