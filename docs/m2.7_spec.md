# M2.7 網子物理、判分顯示、動畫重構、地圖、隊長、FPV 輸入 規格（orchestrator 拍板版）

> 增補於 m2.6 之上。未提及處沿用現狀。

## 1. 網子物理（shared+server，核心改動）
- 廢除「觸網＝死球」。網＝軟障礙：z=0 平面、x∈[±half width]、y∈[0, NET_TOP=2.43]。
- server 逐 tick（或段相交解析）偵測球軌跡穿越網面：
```
接觸點 y ∈ [NET_TOP−NET_TAPE_H(0.15), NET_TOP] → 「擦網帶」：球過網，速度衰減
    v' = v × NET_TAPE_DAMP(0.5)，vy 額外 −0.5（往下帶）→ 貼網翻落對面
接觸點 y < NET_TOP−NET_TAPE_H → 「撞網」：軟反彈近直落（網吸能）
    vz' = −vz × NET_RESTITUTION(0.15)；vx' = vx × 0.5；vy 不變（重力續作用）
兩者皆：以接觸點/接觸時刻生成新 BallLaunch（純函數鐵律照舊），isNetTouch: true 標記，廣播
可多次觸網；發球擦網過網＝好球（let serve，無特判）。落地才依既有 ground/out 判分。
常數全進 shared constants；反彈解算為 shared 純函數（可測）。
```
- shared：`BallLaunch.isNetTouch?: boolean`；net 碰撞解算純函數＋單元測試（帶區/面區/多次反彈時間序）。
- DeathEvent 的 'net' cause 移除（若存在）。

## 2. 連擊/觸次犯規改「觸球無效」
- server：TouchIntent 來自「同隊上一觸的同一人」或「該隊已 3 觸」→ **拒絕觸球**（不裁死球）：不生成 BallLaunch，回 TouchResult `outcome:'illegal_double' | 'illegal_count'`、quality 0，只影響演出。球照原軌跡飛、落地自然判分。
- client：收到 illegal_* 顯示回饋「連擊犯規！」／「觸球次數用盡！」（紅字），H 感覺無效即可（不用鎖鍵，server 每次都拒）。

## 3. 判分顯示
- DeathEvent 確保攜帶：`scoringSide:'A'|'B'`、`cause:'ground'|'out'`（＋落點側資訊若有）。
- client 中央橫幅（1.8s）：「{隊名} 得分 — {原因}」，原因文案：ground→「球落地」、out→「球出界」。用 §5 隊名。

## 4. 地圖（indoor / outdoor）
- shared：`MapId = 'indoor'|'outdoor'`；LobbyState 加 `map: MapId`（預設 indoor）；`CH.SET_MAP {map}`（host-only、lobby 階段）。開賽後 client 沿用 lobby 收到的 map。
- client 環境渲染（gameplay 零差異，純視覺）：
  - indoor：木地板色場地、體育館牆/天花板色背景、冷白光。
  - outdoor：沙色場地、天空藍背景＋太陽方向光、暖光。
- 大廳 UI：host 看得到地圖切換（兩張小卡或 toggle），非 host 顯示當前選擇。

## 5. 隊長與隊名
- captain＝該隊現存成員中最早加入者（離隊遞補重算）。
- shared：LobbyState 加 `captains:{A:string|null,B:string|null}`（playerId）、`teamNames:{A:string,B:string}`（預設「A 隊」「B 隊」）；`CH.SET_TEAM_NAME {name}`（captain-only，server 由發送者推 side；trim 1..12 字元，同 SET_NAME 字元規則）。
- client：大廳隊伍欄標題＝隊名，captain 名字旁「隊長」徽章；captain 的隊名旁有編輯（點擊變 input）；HUD 比分與判分橫幅用隊名。

## 6. 動作動畫重構（client，第三人稱＋FPV 皆適用）
- 蓄力（按住 H）＝**靜止預備式**（不再擺動）：
  - dig：雙臂前伸、雙手交握（platform 姿勢）
  - set：雙手舉高過頭（框球）
  - spike：慣用臂高抬後引、非慣用臂前伸瞄準
- **放開 H 瞬間**＝播放出手動作（~0.35s，朝球方向）：dig 雙臂由低往上撈；set 雙手向上推出；spike 慣用臂由上往下完成揮擊。
- 未蓄力時沿用 idle/move 甩手；dive/jump 疊加規則沿用。
- **FPV viewmodel**：第一人稱渲染自己的雙臂（掛在鏡頭下緣的簡化臂），同步姿勢機（預備式/出手動作/發球持球）→ FPV 也有視覺回饋。頭/身體/名牌維持隱藏。

## 7. FPV 發球方向指示
- FPV 時世界量角器對自己不可讀 → 畫面下方中央新增 **2D 半圓 HUD 弧**（DOM/canvas）：同一個 sweepAngleDeg 純函數＋同步 server 時鐘驅動指針，蓄力值以弧內填充顯示。僅發球階段且輪到自己時顯示。第三人稱不顯示（世界量角器已足夠）。

## 8. FPV 輸入擴充
- FPV 且 pointer locked：**左鍵＝H 等效**（按下蓄力、放開出手；沿用 cancelPendingCharge 防重上鎖誤觸——重上鎖那一下點擊不得開始蓄力）。第三人稱左鍵維持無作用。
- **滾輪選格**（兩種視角皆可用）：九格線性序 `[U,I,O,J,K,L,M,',','.']`，向下滾＝下一格、向上滾＝上一格、頭尾 wrap。選中 J/K/L → touchMode 即時切換；選中技能槽 → 僅 HUD 高亮（selected ≠ active mode，兩種高亮視覺區分），touchMode 維持最後的 J/K/L。
- **Q/E**＝跳上一排/下一排（保持欄位；中排有發球格但發球格不可選，跳排落在 J/K/L 對應欄）。J/K/L 直接按仍然有效（同步 selected 到該格）。

## 9. 修 bug
- **換隊動畫只發生一次**：大廳切隊時的動畫（查 lobbyView 的卡片 transition/class 邏輯）第二次不觸發——修成每次切換都觸發（重排 class/reflow 或 key 重建），或若屬意外副作用則明確做成一致的動畫。
- **球影太大**：落地時影子明顯比球大一圈 → 基準半徑改 ≈ 球渲染半徑（查 ball 半徑，取 ~0.9×），高度放大係數減半；貼地時影子略小於球。
