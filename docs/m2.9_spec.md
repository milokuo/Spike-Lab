# M2.9 — 主選單重設計＋練習模式（2026-07-06）

目標：入口從陽春表單（取名→Create/Join）升級為有遊戲感的標題選單；模式分流成
**練習模式**（單人沙盒房）與**多人對戰**（現行 create/join 流程）。本輪不動任何
玩法判定常數；netcode 只新增「房間建立選項」一個 wire 面。

工作包分工（檔案所有權嚴格分區，可並行）：
- **WP1（client）**：只准動 `packages/client/**`。§3 §4 §5 §6。
- **WP2（server＋shared）**：只准動 `packages/server/**` 與 `packages/shared/**`（僅追加）。§1 §2。
- **WP3（整合驗證）**：跑 §7 全部閘門，修 trivial 整合破口（如常數 unify），其餘回報。

---

## §1 Wire 契約（拍板，雙端據此並行）

1. **房間建立選項**：client 以 `client.create(ROOM_NAME, { mode: 'practice' })` 建練習房。
   - wire 字面值拍板：鍵名 `mode`，值 `'practice'`。缺省／未知值一律視為對戰房（不 throw、不 reject）。
   - WP2 在 shared 追加（供 server 匯入；client 本輪用本地常數避免跨包並行衝突，WP3 統一）：
     ```ts
     export type RoomMode = 'versus' | 'practice';
     export const ROOM_MODE_PRACTICE = 'practice' as const;
     ```
2. **不新增任何 CH channel**。LobbyState / StateSnapshot / DeathEvent / TouchResult 格式一律不變。
3. 練習房 `maxClients = 1` 且 `this.setPrivate(true)`：房碼 joinById 自然失效，朋友不會誤入。

## §2 Server 練習模式（WP2）

- `onCreate(options)`：解析 `options.mode`（防禦式：非 `'practice'` 一律 versus）。practice →
  `maxClients = 1`、`setPrivate(true)`、內部 `isPractice` flag。
- `onJoin`（practice）：照常入座（自動 A0）、照常 LOBBY_STATE；另
  `clock.setTimeout(() => this.startPractice(), PRACTICE_AUTOSTART_MS)`，
  `PRACTICE_AUTOSTART_MS = 300`（必須晚於 LOBBY_BROADCAST_DELAY_MS）。
- `startPractice()` = startMatch 變體：**不建 rotation（維持 null）**、不查 `canStart`、
  `servingId = 唯一玩家`、比分歸零後 `enterServePhase()`。
- **計分凍結**（驗收條件，實作切口由 agent 讀 matchSim.ts 選最小侵入，建議在 room 層
  `finishRally` 分支，不深改 MatchSim）：
  - score 永遠 0:0、永不 gameover、rotation 不動；
  - DeathEvent 照常廣播（cause 照算、`nextServerId` = 自己）；
  - RESET_DELAY 後照常 `enterServePhase()` → 無限「發球→落地→重發」循環。
- **觸球放寬**：practice 下 `illegal_double` 與 `illegal_count` 不成立（可自接連擊 juggle）。
  切口在 rally 合法性檢查層（讀 rally.ts / matchSim.ts 找 legality gate，以 flag 繞過），
  **玩法常數一個都不准動**。
- `onLeave`（practice）：不得觸發 forfeit 分支；房間空了靠 Colyseus autoDispose 收掉。
- **新測試 `packages/server/test/practice.ts`**（jitter.ts 同款：tsx 自起 server 於埠 2601，
  colyseus.js 真連線）斷言：
  1. `create(ROOM_NAME, {mode:'practice'})` 後 ≤1000ms 收到 `phase==='serve'` 且
     `servingId===自己` 的 snapshot（不需 START_MATCH）；
  2. 模擬發球（TOUCH）後球落地收到 DEATH，score 仍 0:0，RESET_DELAY 後 phase 回 `'serve'`；
  3. 對戰房（無 options）行為不變：lobby 停留、canStart gate 照舊。

## §3 Client 選單重設計（WP1）— 美術方向拍板

**風格：競技街機×轉播感**（Mario Tennis 選單 × 球賽轉播包裝）。禁止 generic 置中表單。

- **背景＝實況 3D 球場**：menu 的整片 `rgba(8,8,16,0.92)` 黑幕改為「左深右透」斜向漸層
  （左 ~0.9 → 右 ~0.35）＋輕 vignette，讓後方球場與運鏡（§4）透出來。
- **Palette（CSS custom properties，進 menuStyles）**：
  `--spike-navy:#0b1026`（底）、`--spike-blue:#3fa7ff`（沿用 A 藍）、`--spike-red:#ff5c5c`（沿用 B 紅）、
  `--spike-orange:#ff8a2a`（主 accent 排球橘）、`--spike-cream:#fff6e8`（亮文字）。
- **Typography**：system-ui 900 italic。大標「SPIKE LAB」`clamp(48px, 9vw, 110px)`、
  `skew(-6deg)`、橘→黃漸層字（background-clip:text）；副標「妖球排球」做成小橫幅膠囊。
  不引外部字型檔、不引任何外部資產。
- **Logo**：inline SVG 排球（圓＋三條弧線縫線，描邊風），置於標題旁，可微幅慢轉。
- **版面**：標題區居左上偏中；中央兩張**斜切平行四邊形模式卡**（clip-path）：
  - 「練習模式」— 副文案「單人球場・自由發球與連擊・不計分」；
  - 「多人對戰」— 副文案「開房間邀朋友，或輸入房碼加入」。
  hover：上浮 4px＋橘描邊發光＋箭頭滑入；active 有按壓感。兩卡進場 stagger slide+fade。
- **名字欄**：底部一條「選手名牌」樣式輸入列（persist 既有 `LOBBY_NAME_STORAGE_KEY`），
  兩種模式共用。
- **多人 panel**：點「多人對戰」卡 → 同畫面滑入第二層 panel（Create room 主按鈕／
  房碼輸入＋Join／返回箭頭）。錯誤訊息（現 `lobby-error`）搬進此 panel。
- **練習流程**：點「練習模式」卡 → 直接 `createRoom({mode:'practice'})`，顯示極簡
  「進入練習場…」過場字卡，phase 離開 lobby 後由既有 `setPhaseVisibility` 自然隱藏。
- **WAITING / GAMEOVER 同步換皮**：同 palette／斜切語彙，改半透明玻璃卡（背景不透明度
  降到 ~0.78 露出球場），**結構與行為不動**（slot grid、map picker、team header、
  slot pop 動畫全保留，class 名不改以免弄壞 slotAnimation）。
- **動效紀律**：只准 transform/opacity；150–300ms；`prefers-reduced-motion: reduce` 時
  關閉進場動畫。

## §4 選單背景運鏡（WP1）

- `SceneRenderer` 新方法 `orbitIdle(nowMs)`：相機繞場中心圓周，半徑 13、高 6、
  角速度 0.05 rad/s，`lookAt(0, 1, 0)`。常數進 client `config.ts`（命名 `MENU_ORBIT_*`）。
- main.ts 動畫迴圈：**僅 `connection.room === undefined` 時**每幀呼叫 `orbitIdle`。
  進房後既有 `setCameraForSide` / `followPlayer` / FPV 接管，orbit 不得再碰相機
  （殘留狀態鐵則：入房→離房→再入房循環要驗）。WAITING/GAMEOVER 在房內，維持靜態
  side 相機即可，不 orbit。

## §5 練習模式 client 流程（WP1）

- `LobbyCallbacks` 追加 `onPractice(name: string)`。
- `Connection.createRoom(options?: { mode: 'practice' })` 簽名擴充；wire 字面值
  `'practice'` 以 client 本地常數承載（config.ts，註明 §1 拍板、WP3 會 unify 到 shared）。
- main.ts：practice 進房走 `onRoomJoined` 同款 teardown＋wire，但**不呼叫
  `showWaitingPlaceholder`**（分流参数或独立函式），改顯示過場字卡。
- client 持本地 `isPractice` flag（自己建的房自己知道，不靠 wire）：
  - **scoreboard 於 practice 隱藏**；
  - DeathEvent 橫幅在 practice 顯示中性文案（如「球落地——重新發球」），不播隊伍加分演出；
  - HUD 左上角新增「練習模式」chip＋「離開」鈕（走既有 `leaveToMenu` 全套 teardown；
    FPV 中按 V 解鎖後可點）。pointer-events 僅該 chip 開。
- 離開練習→回選單→再開多人房，必須乾淨（`gameSession.reset()` 既有路徑）。
